# Flash_Async_Demo

---

## Function Description

This example demonstrates flash erase, write, and read verification operations using asynchronous mode.

The asynchronous mode can only operate on non-current flash blocks. Since the program resides in Block 0, this routine can only access the flash region in Block 1.

---

## Hardware Requirements

+ **EVB**: YTM32B1MD1-EVB-Q100
+ **Debugger**: J-LINK v9.2 or later version
