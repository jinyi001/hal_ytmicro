# I2c_Slave_Demo

---

## Function Description

This demo shows that I2C slave mode.

- I2C slave waits for i2c master to send 8 bytes of data.
- After the reception is completed, wait for the i2c master to read 8 bytes of data.

---

## Hardware Requirements

+ **EVB**: YTM32B1MD1-EVB-Q100
+ **Debugger**: J-LINK v9.2 or later version
